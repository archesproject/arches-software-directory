software directory

Discover community-built extensions, applications, tools, and packages available for the Arches platform.

This directory serves as a centralized information source about Arches-related software tools shared by contributors across the Arches open-source community. It is intended to track the breadth of technical options available to those interested in Arches, and provide visibility to and encourage alignment among the community’s technical contributors.

Browsing the Arches Software Directory

The directory provides metadata describing each software item, including its function, development status, licensing information, and parties involved in its development and maintenance. Keywords and additional filters allow for searching the directory via the search bar, and viewing contents by a specific type, development status, or supported Arches version. Inclusion of the Arches logo indicates code that is officially maintained by the Arches Project.

Submitting an item to the Arches Software Directory

Contributors are invited to submit applications, extensions, other Arches-specific tools, and data model packages through a pull request via the button below. Contributors are encouraged to share works-in-progress to provide visibility and promote alignment early in the development process. Regardless of authorship or code location, all submitted items must be shared under an appropriate open-source licence (e.g., AGPL3). The Getty Conservation Institute, as sponsor of the Arches Project, retains editorial control over this directory.
